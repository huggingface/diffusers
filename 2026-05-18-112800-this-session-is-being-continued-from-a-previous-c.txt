❯ claude code的工作树有啥用                                                     

⏺ Claude Code 的 worktree(工作树) 是用 git worktree 给 agent 开一个独立的 repo
  副本,主要用途:

  核心场景
  1. 并行多 agent 不打架 — 多个 subagent 同时改代码,各自一个工作树,互不覆盖
  2. 隔离实验性改动 — 不想污染当前 checkout(比如你正在 review
  PR、bisect、留了未提交 stash),让 agent 在别处折腾
  3. 自动清理 — 如果 agent 没改任何文件,工作树自动删除;改了就保留路径+分支给你看
   diff

  实际怎么用
  - 我 spawn agent 时加 isolation: "worktree",系统在 .git/worktrees/
  下开一个新分支
  - agent 在那个目录里跑代码、改文件、commit
  - 结束后我拿到 worktree 路径和 branch 名,你想合就 git merge,不想合直接 git 
  worktree remove 扔掉

  用户层面也能跑 — superpowers:using-git-worktrees skill
  就是干这个的,启动新功能开发前用,确保和当前 workspace 隔离。

  啥时候不用
  - 单线程小改动直接在主 checkout 上做更方便
  - 测试要跑很重的 build/install(每个 worktree 都得重新安装依赖)
